# Tour Memory — brand standards

Find it. Tour it. Remember it. Make it home.

Voice-first AI home finding companion.

## Palette
- Forest green #184D3D: primary, text, buttons.
- Fresh green #B9FFA2: accent, dark-background highlights.
- Warm cream #F7F4EB: backgrounds.
- Leaf green #79C94A: secondary mark accent.

## Typography
Inter or system sans-serif; use bold headings, clear labels and generous spacing.

## Logo
House outline and curved path signify a journey home. Keep clear space around the mark; do not stretch. Use monochrome mark for dark display contexts. G2 rendering must be verified against SDK capabilities.

SVG assets are manually reconstructed from the approved concept, not exact traced artwork. PNG exports are transparent except for the app icon. Trademark clearance has not been performed.
